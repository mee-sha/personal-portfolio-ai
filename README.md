# 🌸 Kavya's Portfolio

My personal portfolio website, built to showcase my work as a Data Analyst and my projects across data analytics and AI.

The fun part is the **Ask Me** assistant 🤖 where visitors can ask questions about my projects, skills, and experience instead of just reading through a static portfolio.

- Flask
- Groq
- JavaScript
- HTML & CSS
- SQL
- Power BI

## 💭 Why I Built This

I wanted something more personal than a basic portfolio.

This project took me through a *lot* of debugging, especially getting the frontend, Flask backend, API, and AI assistant to work together.

It took way longer than I expected — but seeing the AI assistant finally answer questions on my own portfolio made it completely worth it. 😭
